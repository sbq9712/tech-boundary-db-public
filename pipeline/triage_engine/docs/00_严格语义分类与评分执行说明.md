## 1. 生效文件与执行顺序

1. `文献技术分类规则_行业图景版.docx`：技术领域分类的文字语义基准，按 125 条完整路径执行。
2. `新闻类型语义分类规则_行业图景版.docx`：新闻类型 T01–T25 的语义基准（2026-09-18 再生成版，见 §4）。
3. `01_新闻类型分类评判表.xlsx`：类型语义定义、必要条件、排除条件与跨类型裁决（含 2026-09-18 新增 C-T10–C-T13、2026-09-19 C-T14、2026-09-20 C-T15）。
4. `03_技术领域参数库.xlsx`：分类完成后，把完整技术路径映射到评分域并装载评分参数。它不是领域分类器。
5. `02_技术领域×新闻类型评分规则表.xlsx`：只在技术领域和新闻类型均完成语义裁决后，按机制表评分（含 2026-09-18 优先级分层 P0/P1/P2）。

执行顺序：**大模型语义判定（基准参考）→ 规则层校验/兜底 → 评分机制链 S3–S8 → 优先级分层定档与排序**。

## 2. 分类硬约束（v1.02 修订）

- **大模型语义判定为主**：领域与类型由大语言模型通读标题与正文（含摘要/摘要性段落/digest）语义裁决；词表、正则、关键词只用于候选召回与证据定位，不得单独决定分类，也不得以"未命中词表/必要条件不足"推翻语义上明确的主对象。
- **默认域内原则（本轮核心修订）**：除能给出明确域外理由（内容与行业图景及扩展技术域完全无关，如纯娱乐、体育、一般财经宏观）外，所有记录必须给出领域与类型划分。**废止"动作、指标和瓶颈不作为域内前置条件"式的域内拒绝**——主对象明确即入域，动作/指标/瓶颈只是评分证据，不是入域门槛。
- **标题语义足以判定时不得以正文缺失拒绝**：文献 RSS 未取到摘要（正文为空）时，按标题语义直接判域判型（T01 论文由文献载体身份确定）；已删链/删文的微信文章，用已抓取的 digest/标题语义判定，不得因"正文不足"落域外或 T25。
- **论文对象落入行业图景的，按文章内容自行判断并划分**；基准文档暂无对应路径但主对象稳定明确且有统一管理价值时，新增扩展域（2026-09-18 已新增 E25 碳市场与温室气体监测；E02 水电/E15 电网技术与虚拟电厂已补英文判定词表；**2026-09-19 新增 E26 地热能利用**——中深层地热/干热岩/超临界 CO2 取热，CO2 作地热循环工质归 E26 不归 CCUS）。新增领域必须记录语义定义、纳入边界、排除边界和通用评分机制。
