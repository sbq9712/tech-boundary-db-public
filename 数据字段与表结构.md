### users（用户）

| 字段 | 类型 | 说明 |
|------|------|------|
| username | String(64) PK | |
| password_hash | String(256) | PBKDF2-SHA256（260000 轮） |
| display_name | String(100) | 显示名（迁移 0012） |
| role | String(20) | admin / user（迁移 0012） |
| is_active | Boolean | 账号是否启用（迁移 0012） |
| created_at | DateTime | |
| password_changed_at | DateTime | 密码修改时间（迁移 0006） |
| last_login_at | DateTime | 最后登录时间（迁移 0012） |

> 初始管理员由 `.env` 中 `TECHDB_INITIAL_ADMIN_USERNAME` / `TECHDB_INITIAL_ADMIN_PASSWORD` 配置，首次启动时创建一个管理员。不批量创建账号。
