# 不设"开放问题"节点；行业判断 = 结论 + 论据 + 拐点标准

拒绝独立的"开放问题"节点类型。结构未收敛的问题沿因果链下追后都会落回标准建模（卡点/路线/证据）：如"氚自持"下追三层——供应链问题 → 缺氚原因（半衰期短、存量少）→ 解决路线（月球采矿/自产）→ 各自落回卡点本性四象限（ADR-0006）。"结构未收敛"通常是追得不够深，不是需要新节点类型。

行业判断节点的 schema 固定为三段：**结论 + 论据（引用卡点/路线判断）+ 拐点标准**。拐点标准是条件句（"当 X 技术/资源/政策出现 Y 变化时，行业因 Z 基本面变化迎来拐点"），同时充当行业层的预警触发谓词，与 ADR-0004 重审机制衔接。结论允许带主观概率的条件判断（"若第一性理论未建成，则聚变永远是不完全安全的技术"），只要基于知识库沉淀和严格逻辑推理可推出。

卡点本性保持技术侧四类封闭枚举（ADR-0006）；**供应链不是标签，升为系统侧一等类别**（ADR-0008，本段原"供应链成因标签"方案作废，由 ADR-0008 取代）。

_Avoid_: 开放问题节点、无拐点标准的行业结论
