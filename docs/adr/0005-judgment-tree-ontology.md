# 判断树自建本体：行业-路线-技术三层自下而上聚合，广度分类仅作链接

判断挂在自建本体上（行业判断 → 路线判断 → 卡点/指标判断 → 观测证据），广度 77 分类叶子只作采集/检索组织，通过映射表链接到判断节点，不改造广度分类树。

层间关系是**自下而上聚合**：路线判断是行业判断的直接输入，行业判断（如"哪条技术路线更有潜力"）引用路线判断作为支撑，不由行业层另起炉灶写结论。判断变更沿树向上传导（卡点判断变 → 路线判断进重审 → 行业判断视情况跟随），与 ADR-0004 的重审触发机制衔接。

结构深度自适应：有路线分叉的领域（核聚变的托卡马克/仿星器/FRC/Z箍缩）用完整四层；无清晰路线的领域可省略路线层。不强制定死根节点称呼，但强制"卡点/指标判断必须挂证据，行业判断必须引用路线判断"。

_Avoid_: 把判断挂到广度 77 叶子上（粒度错配：核电一个叶子装不下裂变+聚变多路线）、细分广度分类树来迁就判断（动上游资产）、行业判断不引用路线判断的空中楼阁
