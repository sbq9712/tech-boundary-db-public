# 判断的腐化政策：分层动态更新 + 双过滤器触发调研

行业判断不实时自动重写（与 ADR-0003 一致：判断本体只有人审后变更），但按以下分层动态更新：

1. **被动挂载（代码级，零 AI）**：新观测命中信号规格即挂到对应判断节点，判断不动。
2. **周批比对**：节点累积的普通新观测每周合并跑一次 AI 增量比对，产出判断变更提案进人审队列。
3. **即时调研（双过滤器触发）**：新情报同时满足 ①命中信号规格（相关性，代码级过滤先行）②情报评分达到预警门槛（重要性，组内同步建设中的评分机制）→ 触发一轮针对性质询调研：评估该情报可信度 + 连同周边证据对判断树的影响，产出带证据的判断变更提案。人审后视情况更新判断树。

信号过滤在评分之前（便宜的先跑，评分是 AI 调用）。"判断可信度和实际情况"的调研范围是**影响评估**（情报真伪 + 对判断树哪些节点的冲击 + delta 建议），不是孤立的真假核实。

查询接口上每个判断节点显示 `as_of`（证据截至）与 `last_reviewed`（最后人审），超龄节点进入重审队列——重审按节点粒度，不按整领域。

_Avoid_: 查询时实时重综合（AI 直接产出判断，绕过审核）、全自动判断更新、整领域全量重审
