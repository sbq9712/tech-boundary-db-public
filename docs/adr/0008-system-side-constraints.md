# 系统侧四类：约束性卡点可能在"别人手里"，与技术侧正交成一等层

行业落地的约束不只来自技术本体。系统侧卡点的定义性特征：**约束来自其他行为者的行为或协调失败，解决者不是技术开发者**。封闭枚举四类，恰好对应四类"别人"：

1. **准入审批** — 监管者不放行（安全认证、并网规则、出口管制、临床审批）。仅指**许可性**政策；价格性政策（补贴、碳价）归技术侧经济问题的拐点条件。信号：制度事件。
2. **供应链** — 关键原料/部件上游不给（氚、稀土、绿氢、光刻胶）。信号：产能、价格、地缘事件。
3. **生态配套** — 互补投资者得先动（管道、充电桩、可融资合同、承购协议）。本质是"谁先投"的协调博弈。信号：首个大额承诺落地。
4. **社会接受** — 公众/社区不答应（核电选址、CCS 管道、人造肉）。**归约优先**：能归准入审批或生态配套的先归约，真拒绝场景才挂此。信号：态度转折事件。

删除"需求确定性"：需求（订单、溢价、渗透率）是技术侧经济问题的收入侧拐点变量，不是行为者约束。

行业判断 = 技术侧结论 + 系统侧结论 + **约束性卡点归属**（最弱环节，两侧一起找、只选一个）。拐点标准写在约束性卡点上：在技术侧则行业时钟由研发走（监测学习曲线/实验事件），在系统侧则行业时钟由别人走（监测制度事件/外部价格）。跨侧流动四种：系统解技术卡（价格下降消解经济卡点）、技术解系统卡（电解槽学习曲线改善供给）、系统卡死技术（氚依赖 CANDU 堆副产）、政策翻转经济性。互为因果时显式建链防重复计数。

约束性卡点判定本身是过审判断，不可 AI 自动标注（主约束识别错误是本方法论第一失败模式）。

_Avoid_: 把供应链当标签挂在技术侧四维上（有不可归约反例：氢冶金约束性卡点是绿氢供给，不存在于钢厂技术的四维中）、"没找到卡点"当"没有卡点"
