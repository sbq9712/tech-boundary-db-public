# 跨领域扫描视图：机械指标层，发现入口而非结论出口

新增跨领域扫描视图，回答"30 个领域里，这个月哪几个在冒烟"。每个领域显示三个纯机械指标：

1. **新证据速率** — 通过广度分类映射统计该领域近月新增情报/文献量及环比（JRC activeness 思路：突然变热 = 有事发生）。不依赖判断树。
2. **信号命中数** — 该领域卡点信号规格近期命中的情报条数。依赖卡点结构化。
3. **待审堆积** — 该领域判断变更提案队列深度。依赖重审机制。

设计纪律：**只呈现"动静"，不产出"潜力"结论**——潜力判断是行业判断，须过审（ADR-0003）；且不同主约束类型需要不同估计器，合成单一潜力分违反维度可预测性不对称。跨领域扫描是发现入口（人扫一眼挑领域进认知面板），不是结论出口。

覆盖策略：30 个领域全上（新证据速率首日即可全量，仅依赖分类映射）；信号命中与待审数随卡点结构化渐进填充，用可见的空位驱动文档结构化。

深度调研文档的产出主体是 Agent：执行调研管线产出文档草案，人审核、挑战、与 Agent 迭代定稿（本 ADR 补充 ADR-0009：审核界面须支持挑战式迭代——被推翻的论证与修正理由沉淀为判断质量的证据链，不是简单通过/驳回）。

_Avoid_: 潜力评分自动排行、无结构化领域的空指标伪装成零分、审核界面做成一键通过

（附）Agent 调研管线自主度（2026-08-18 决定）：断点 1 调研计划与断点 3 成文后为硬停（等确认才继续），断点 2 证据/卡点候选为软停（产出中间物继续跑，人可随时打断），断点 4 判断入树过审（ADR-0004 已定）。证据源边界为**半开**：库内为主，外网仅补库内缺失的关键证据，外网证据标 `external`、不入库、不得作为唯一论据；判断的核心论据必须有库内或可入库的证据。**服务器外网访问 = IT 申请的网址白名单制（已确认可行），待整理白名单清单——arXiv、期刊 DOI 域名、专利局、IEA/DOE 报告页等候选，另行任务化。**
