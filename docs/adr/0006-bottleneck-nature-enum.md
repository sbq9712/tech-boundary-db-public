# 卡点本性：技术侧四维封闭枚举，显式限定作用域为"技术本体"

技术侧卡点的"本性"是封闭枚举，四个值，作用域显式限定为**技术本体自身**（第一性推导：人造物可部署的四个必要条件——自然法则允许、可重复制造、行为可预测、资源回报正当——各对应一维）：

1. **物理限制** — 自然规律不允许（热力学极限、Lawson 判据）。突破形态：绕路（换路线）。监测：指标逼近理论值。
2. **工程问题** — 理论可解，造出来难（良率、寿命、规模化）。突破形态：学习曲线爬坡。监测：Wright 定律斜率。
3. **经济问题** — 造得出来，但太贵。突破形态：成本过线。监测：成本曲线 vs 替代品价格带（含政策驱动的价格移动——**补贴/碳价等价格性政策并入本维拐点条件，不单列**）。
4. **认知论限制** — 连可靠的预测模型都没有（等离子体湍流控制）。突破形态：事件型黑箱突破（不连续）。监测：事件信号，不设指标阈值。

四维全清 ⇒ "技术侧无已知障碍"（措辞纪律：不等于"没有卡点"，判断质量取决于排查覆盖度，❓未知项即覆盖度的显式记录）。TRL 是证据性概念（演示过了没有），四维是诊断性概念（什么在挡路）；四维全清 + 运行环境演示 ⇒ 才等价 TRL 8-9。

本 ADR 修订原 0006：删除"供应链成因标签"方案（供应链升为系统侧一等类别，见 ADR-0008）；下游信号规格形态、突破判据、AI 比对模板由本字段驱动，新增类型需走 ADR。

_Avoid_: 自由文本本性、把认知论限制当工程子型（监测逻辑不同）、把价格性政策当独立系统侧卡点、四维全清即宣称 TRL 9
