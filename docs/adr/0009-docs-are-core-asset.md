# 知识库文档是核心资产，判断树是散点认知层

知识库 § 结构文档是凝结知识、形成逻辑判断的**核心资产**——长推理链、因果下追、综合裁决只在文档的散文里成形。判断树（卡点/路线/指标/信号节点）是**散点认知层**：系统的可计算资产，承担更新传导、信号监测、查询和聚合。

两层数据流向（异质双向）：
- **文档 → 树**：AI 从文档提取散点（卡点及其侧/类型、拐点标准、信号规格），树节点引用文档段落为出处。树是文档的结构化投影与检索加速层。
- **树 → 文档**：新观测挂载、重审触发（ADR-0004）时，比对报告指向文档相关章节；判断的权威版本在文档，人审改文档，树重新提取。

判断的 single source of truth 是文档；树的完整性目标只是"文档中可结构化部分的忠实投影"，不强求覆盖全部散文。

_Avoid_: 树为唯一事实源（丢失推理链）、文档仅为渲染产物（凝结功能不可替代）、一次性全量迁移运动（老领域借重审逐步结构化，新领域树优先起步）
